# RMC Production & Consumption Dashboard

## Project Overview
An interactive Power BI dashboard project designed to analyze Ready-Mix Concrete (RMC) production, delivery performance, revenue, and raw material consumption.

## Tools Used
- Microsoft Power BI
- DAX
- Advanced Excel
- Data Visualization
- MIS Reporting

## Business Objectives
- Monitor actual production against production targets.
- Analyze cement, sand, aggregate, water, and admixture consumption.
- Identify material consumption variances.
- Compare production and performance across plants and clusters.
- Track revenue, deliveries, and monthly trends.

## Dashboard Pages
1. Executive Overview
2. Material Consumption Analysis
3. Plant & Client Performance

## Files Included
- `RMC_Production_Consumption_Dashboard_Project.xlsx` — sample dataset and DAX measures.
- `RMC_PowerBI_Project_Guide.txt` — setup instructions and dashboard design guide.

## Dataset
The workbook contains synthetic sample data for 2025, intended for learning and portfolio demonstration. Material rates, prices, and recipes are illustrative.

## How to Use
1. Download the Excel workbook.
2. Open Power BI Desktop.
3. Select **Get Data → Excel Workbook**.
4. Import the relevant sheets.
5. Create the relationships and DAX measures described in the project guide.
6. Build and save your Power BI report as a `.pbix` file.
